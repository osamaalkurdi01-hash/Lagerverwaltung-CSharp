# Lagerverwaltung (C#)

## Beschreibung
Eine einfache Konsolenanwendung zur Verwaltung von Produkten und Lagerbeständen. Entwickelt mit C# und Visual Studio.

## Funktionen
- Produkte hinzufügen
- Alle Produkte anzeigen
- Produkte suchen
- Lagerbestände ändern
- Produkte löschen
- Eingaben überprüfen

## Technologien
- C#
- .NET
- Visual Studio

## Lerninhalte
- Klassen und Objekte
- Listen (List<T>)
- Schleifen und Bedingungen
- Eigenschaften mit get und set
- Eingabevalidierung mit int.TryParse

## Projektziel
Mit diesem Projekt möchte ich meine praktischen Programmierkenntnisse in C# erweitern und die Grundlagen der objektorientierten Programmierung anwenden.
